# ВышКат

ДЗ №1 по КПО: консольный учёт транспорта и вещей на Go.

## Запуск и проверка

Нужен Go 1.22 или новее

```sh
go run .
gofmt -w *.go
go build ./...
go test ./... -cover
```

## Структура

- [model.go](model.go): интерфейсы и структуры транспорта и вещей.
- [park.go](park.go): `Park`, приёмка, отчёты и `ServiceCenter`.
- [main.go](main.go): ручной DI-контейнер `Container` и демонстрация.
- [park_test.go](park_test.go): тесты поведения на стандартном `testing`.

## SOLID и вопросы

- **S:** `ServiceCenter` отвечает за техосмотр, `Park` — за учёт, демонстрация — за вывод.
- **O:** новый вид транспорта реализует `Vehicle`, потребитель энергии — `EnergyConsumer`.
- **L:** все виды транспорта работают через один контракт `Vehicle`: оценка 1–10, признак исправности, название и номер.
- **I:** инвентаризация, энергия и техосмотр разделены.
- **D:** `Park` получает `Inspector` через конструктор и не создаёт техосмотр сам.
- **Что ограничено:** SRP у `Park`. он и хранит список, и считает отчёты.
- **DI:** `NewContainer` выбирает обычный техосмотр при `nil` или принимает подмену и собирает `Park`.
- **Тесты:** `TestInspectionDecision` передаёт `stubInspector` через `NewContainer` и проверяет принятие и отказ независимо от исправности. `TestForBeginners` фиксирует границу 5/6 и оценки 1/10. Есть проверки расхода, вещей, номеров и неверных данных.
